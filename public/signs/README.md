# Créditos das placas — AprovaCNH

Os arquivos SVG nesta pasta foram copiados dos assets de placas publicados no projeto de referência Roundeprigous/simulado-cnh, que declara como origem as páginas individuais do Wikimedia Commons. O arquivo `CREDITS.txt` preserva, para cada SVG, a URL de origem, autoria e licença informada pelo projeto de referência.

**Licenças:** a pasta contém arquivos identificados como domínio público e arquivos identificados como Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0). A licença aplicável é a registrada para cada arquivo em `CREDITS.txt`; não se presume que todos os SVGs compartilhem a mesma licença.

**Integridade:** os SVGs foram transferidos sem reconstrução gráfica. Durante a ingestão foi verificada a ausência de elementos `script`, handlers de evento, `foreignObject`, imagens embutidas e referências externas de imagem.

**Uso no BNQ:** `sign_code` guarda o código informado pela questão. `sign_asset_codes` lista somente os códigos para os quais há SVG correspondente e efetivamente incluído nesta pasta. Ausência de um SVG não autoriza substituir a placa por uma figura parecida.

Projeto de referência: https://github.com/Roundeprigous/simulado-cnh
